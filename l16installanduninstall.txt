        => Install Application 
            sudo apt install packagename  or sudo apt install -y packagename ( Automatic Yes to Prompts ) 
            sudo apt install -s packagename  ( -s flag = Simulate Installation , which mean without actually installing the package )

            sudo apt update ( must run before install new app )

        => Firewall ( UFW = Uncomplicated Firewall ) 

            ufw app list 
            ufw status 
            ufw status numbered 
            ufw reload 
            sudo ufw enable     ( Note :: beware before you enable firewall , that can be lock yourself )
            ufw status 
            sudo ufw disable

            sudo ufw enable 
            sudo ufw deny from 103.81.113.17            ( Block an IP Address ) 
            sudo ufw allow from 103.81.113.17            ( Allow an IP Address )

            sudo ufw deny from 103.81.113.17            ( Block a Subnet ) 

            sudo ufw deny in on wlp2s0 from 192.168.100.0   ( Block Incoming connection to a Network Interface )
            sudo ufw allow in on wlp2s0 from 192.168.100.0   ( Block Incoming connection to a Network Interface )

            ufw status 
            ufw status numbered 

            sudo ufw delete allow from 103.81.113.17        ( Delete UFW rule ) 
            sudo ufw delete 3 

            sudo ufw allow ssh 
            sudo ufw allow http 
            sudo ufw allow https 

        => Remove Package 
            (i). Remove Package 
                sudo apt remove vlc 

            (ii). Remove a package and it's configuration files 
                sudo apt purge vlc 

            (iii). Clean Up Unused Dependencies 
                sudo apt autoremove 

                = option 
                    sudo apt-get clean 
                    sudo apt-get --fix-broken install
