=> Step 7 : Set Password For Root Account       ( For Mysql 8.0 and later versions )

    => mysql_native_password Plugin 
        Step 1 => sudo nano /etc/mysql/conf.d/mysql.cnf
        Step 2 => [mysqld] mysql_native_password=ON (or) Ctrl + O ၊ Enter  Ctrl + X Exit  
        Step 3 => sudo systemctl restart mysql


    sudo mysql -u root 
    
    => Not Working Code
        ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'mydatabase1752005@#$';

    => Working Code 
        ALTER USER 'root'@'localhost' IDENTIFIED WITH caching_sha2_password BY 'mydatabase1752005@#$';

    GRANT ALL PRIVILEGES ON *.* TO 'root'@'localhost' WITH GRANT OPTION;
    FLUSH PRIVILEGES;

    exit        or     \q 
    sudo mysql -u root -p 
    my 
    exit        or     \q 

    mysql -u root -p -h yourserverip 
    mysql -u root -p -h                                     // access deny ( cuz root account don't have remote permission )
